`src/perf_io` contains 9 methods of reading a file with a 1-8 digit number on each line generated by `generator.py` which output to an array of `8[u8]`s.
`src/perf_conv` contains 5 methods of parsing that array into an array of `u64`s.

# Compilation
Written using zig version 0.17.0-dev.1158+1d1193aa7.

```
zig build -Doptimize=ReleaseFast
```

# Usage

```
./zig-out/bin/perf_io [file] [method (1-9)]
```

```
./zig-out/bin/perf_conv [file] [method (1-5)]
```

## Example Output:

```
./zig-out/bin/perf_io large.md 6
char count = 394442053
time = 330
```

```
./zig-out/bin/perf_conv large.md 5
sum = 35
time = 83
```
